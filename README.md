# 🌐 Portafolio Profesional & CV Web

Sitio web personal e interactivo diseñado para la presentación profesional de mi perfil como estudiante de la **Licenciatura en Informática (UNAM)**, destacando proyectos académicos, formación técnica, habilidades en desarrollo de software y canales de contacto.

---

## 🚀 Secciones del Sitio

* **👤 Perfil (`index.html`):** Resumen profesional, visión técnica y tecnologías principales.
* **📂 Proyectos (`proyectos.html`):** Galería interactiva con enlaces directos a repositorios de GitHub con código fuente de desarrollos web, bases de datos y algoritmos.
* **🎓 Formación (`formacion.html`):** Trayectoria académica, certificaciones y competencias clave.
* **✉️ Contacto (`contacto.html`):** Formulario e información directa de contacto profesional.

---

## 🛠️ Tecnologías Utilizadas

* **Estructura y Marcado:** HTML5 semántico
* **Estilos y Layout:** CSS3 personalizado, Bootstrap 5.3 (Diseño responsivo y componentes modernos)
* **Iconografía & Tipografía:** Bootstrap Icons
* **Despliegue / Hosting:** GitHub Pages
